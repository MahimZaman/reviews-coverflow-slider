# Reviews Coverflow Slider

Displays entries from the Reviews custom post type in a Swiper coverflow carousel.

## Installation

1. Place this directory at `wp-content/plugins/reviews-coverflow-slider/`.
2. On the WordPress Plugins screen, activate **Reviews Coverflow Slider**.

## Usage

Publish review entries in WordPress, then add `[reviews_carousel]` to the page where the carousel should appear.
